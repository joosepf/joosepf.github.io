EesmärkGoal

Luua modulaarne robotiplatvorm, millele saab lihtsalt lisada erinevaid sensoreid ja laiendusi.

Create a modular robot platform to which different sensors and extensions can easily be added.

KirjeldusDescription

Projekt sai alguse soovist arendada paindlikku ja laiendatavat roboti aluspõhja, mis oleks sobilik erinevate katsete ja projektide jaoks. Kasutatud on 3D-prinditud osi ning juhtimiseks Arduino platvormi.

The project began with the wish to develop a flexible, extensible robot base suitable for a range of experiments and projects. It uses 3D-printed parts and an Arduino platform for control.
