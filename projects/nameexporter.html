EesmärkGoal

Luua õppejõule tarkvaraline lahendus, mis töötleb Moodle'ist saadud tudengite nimekirju ning esitab need soovitud vormingus.

Create a software tool for a lecturer that processes student lists exported from Moodle and outputs them in the desired format.

KirjeldusDescription

„Tarkvaraprojekti“ kursuse raames loodud tööriist, mis loeb Moodle'i HTML-ist välja vajalikud andmed ning genereerib Exceli- või tekstivormingus nimekirjad. Graafiline liides on loodud GTK4 raamistikus. Minu vastutusalaks oli graafiline liides ja vigade parandamine.

A tool built for the “Software Project” course that parses the needed data out of Moodle HTML and generates lists in Excel or text format. The GUI is built with the GTK4 framework. My responsibility was the GUI and bug fixing.
