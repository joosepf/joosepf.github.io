Liikumist toetav mängupultMovement-based game controller

PythonArduinoPythonArduino

EesmärkGoal

Luua mängupult, mis sunnib mängijat liikuma.

Create a game controller that forces the player to move.

KirjeldusDescription

Projekt ühendab Wii-puldi ja kõndimismasina, et mängija peaks mängusisese liikumise ja tegevuse jaoks füüsiliselt liikuma. Arduino jälgib liikumist ja edastab info arvutisse, kus Python saadab liigutused mängu.

The project combines a Wii remote and a treadmill so the player has to physically move for in-game movement and actions. An Arduino tracks the motion and sends the data to a computer, where Python passes the movements on to the game.
